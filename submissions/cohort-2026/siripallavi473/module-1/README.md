## What this is 

This project is an Artificial Neural Network (ANN) based regression project. The aim of the assignment was to build and train an ANN model to learn the relationship between input features and a continuous target value, and then use the trained model to make predictions.

## How to run it

pip install numpy pandas matplotlib plotly

Open ANN.ipynb in Google Colab or Jupyter Notebook and run the cells from top to bottom.

Make sure the preprocessing.csv dataset is available at the path used in the notebook.

## What I learned

I learned how an Artificial Neural Network can be used for regression problems and how data is passed through different layers of the network.

## What I struggled with

I initially struggled to understand how the different layers and neurons in an ANN work together to produce a prediction.
