# Submissions

Student work lives here, one folder per student per cohort.

```
submissions/
└── cohort-2026/
    ├── _TEMPLATE/          ← copy this to start
    └── <github-username>/
        ├── student.json
        ├── README.md
        └── module-1/
            ├── README.md
            └── ...code...
```

**You only ever create files inside your own folder.** A pull request that touches
anything else is rejected automatically by CI.

Full walkthrough: [CONTRIBUTING.md](../CONTRIBUTING.md)
