## Lesson 6.4 — Math for AI

This lesson comes last on purpose. You've already used all of it — in the gradient descent
loop in 6.1, the layer stack in 6.2, and the attention formula in 6.3. Now we name the
parts.

You need far less than a maths degree. You need four things: **linear algebra**,
**calculus**, **probability**, and enough notation to read a paper without panicking.

## 1. Linear algebra — the shape of the data

**Everything is a tensor.** A tensor is just an array with a number of dimensions:

| Name | Dimensions | Example |
|---|---|---|
| Scalar | 0 | a single loss value, `3.7` |
| Vector | 1 | one embedding, `[0.2, −1.4, 0.8, …]` |
| Matrix | 2 | a batch of embeddings, or a layer's weights |
| Tensor | 3+ | a batch of images `(batch, height, width, channels)` |

### The dot product

The single most important operation in machine learning:

```
a · b = a₁b₁ + a₂b₂ + … + aₙbₙ
```

Multiply element-wise, add it all up, get one number. That's how a neuron combines its
inputs (`w · x`), and it's how attention scores query against key. It measures alignment:
large when two vectors point the same way, zero when perpendicular, negative when opposed.

**"Similar embeddings have a high dot product"** is the entire basis of semantic search.

### Matrix multiplication

A whole layer at once. If `X` is `(batch × features)` and `W` is `(features × units)`:

```
Y = X @ W        →  (batch × units)
```

**Inner dimensions must match; outer dimensions survive.** That one sentence resolves
most shape errors you'll ever hit:

```
(32 × 784) @ (784 × 128) → (32 × 128)   ✓
(32 × 784) @ (128 × 784) → error         ✗  784 ≠ 128
```

When PyTorch says `mat1 and mat2 shapes cannot be multiplied (32x784 and 128x784)`, it's
telling you the inner dimensions disagree. Transpose one, or you built the layer wrong.

```python
import numpy as np
X = np.random.randn(32, 784)
W = np.random.randn(784, 128)
print((X @ W).shape)      # (32, 128)
```

### Also worth knowing

- **Transpose** (`Aᵀ`) — flip rows and columns. That's the `Kᵀ` in the attention formula.
- **Norm** (`‖v‖`) — a vector's length, `√(v·v)`. "Gradient clipping at norm 1.0" means
  shrinking gradients whose length exceeds 1.
- **Cosine similarity** — `(a·b) / (‖a‖‖b‖)`. The dot product with magnitude divided out,
  giving −1 to 1. The standard way to compare embeddings.

## 2. Calculus — how learning happens

### Derivatives

A derivative answers: **if I nudge this input slightly, how much does the output move?**

```
df/dx  — rate of change of f with respect to x
```

That's all training needs. "If I increase this weight a little, does the loss go up or
down, and by how much?"

### Gradients

For a function with many inputs, the **gradient** `∇f` is the vector of all its partial
derivatives — one per parameter:

```
∇L = [ ∂L/∂w₁ , ∂L/∂w₂ , … , ∂L/∂b ]
```

It points in the direction of steepest *increase*. So to reduce loss, step the other way:

```
θ ← θ − α∇L
```

This is gradient descent. That one line is the whole of training, from lesson 6.1's two
parameters to a frontier model's billions.

### The chain rule

How derivatives compose through layers:

```
if  y = f(g(x))   then   dy/dx = f′(g(x)) · g′(x)
```

A network is deeply nested functions — `loss(layer₃(layer₂(layer₁(x))))`. To find how a
first-layer weight affects the loss, multiply the derivatives along the path back from the
loss to that weight.

**Backpropagation is the chain rule, computed once per layer and reused.** That's the
entire insight.

It also explains two classic failures:

- **Vanishing gradients** — many factors below 1 multiplied together → near zero → early
  layers stop learning. (Why ReLU replaced sigmoid in hidden layers.)
- **Exploding gradients** — factors above 1 → astronomically large → `NaN`. (Why gradient
  clipping exists.)

## 3. Probability — what the outputs mean

### Distributions

A model's output layer rarely gives an answer; it gives a distribution over answers.
**Softmax** turns arbitrary numbers ("logits") into probabilities that sum to 1:

```
softmax(xᵢ) = e^xᵢ / Σⱼ e^xⱼ
```

Exponentiate everything (making it positive, and amplifying differences), then normalise.
That's what produces the token probabilities in lesson 6.3, and what temperature scales
before the exponential.

### Cross-entropy loss

For classification, the loss for a single example is:

```
L = − log(p_correct)
```

The probability the model assigned to the *right* answer, negatively log'd.

- Model said 0.99 for the correct class → loss ≈ 0.01. Barely corrected.
- Model said 0.01 for the correct class → loss ≈ 4.6. Corrected hard.

**Confident and wrong is punished enormously**, which is exactly the incentive you want.

### Expectation and variance

- **Expectation** `E[X]` — the average over many samples. Your loss is an expectation over
  the data.
- **Variance** — how spread out the values are. High variance in gradients is why we use
  batches: averaging over 64 examples gives a steadier direction than one example.

## 4. Reading the notation

The symbols that stop people, translated:

| Symbol | Means | In plain terms |
|---|---|---|
| `Σᵢ xᵢ` | sum over i | a `for` loop that adds things up |
| `Πᵢ xᵢ` | product over i | a `for` loop that multiplies |
| `θ` | theta | "all the model's parameters", collectively |
| `α` or `η` | alpha / eta | learning rate |
| `∇L` | gradient of L | the list of slopes, one per parameter |
| `∂L/∂w` | partial derivative | slope of L in the `w` direction only |
| `ŷ` | y-hat | the prediction (vs `y`, the truth) |
| `𝔼[X]` | expectation | the average |
| `argmax f(x)` | the x that maximises f | "which option scored highest" |
| `x ~ D` | x sampled from D | drawn at random from distribution D |
| `‖v‖` | norm | length of the vector |
| `Aᵀ` | transpose | rows and columns swapped |

Attention, decoded completely:

```
attention(Q, K, V) = softmax(QKᵀ / √dₖ) · V
```

- `QKᵀ` — every query dot-producted with every key → a matrix of similarity scores
- `/ √dₖ` — divide by the square root of the dimension, so scores don't grow huge and
  saturate the softmax
- `softmax(...)` — turn the scores into weights summing to 1
- `· V` — use those weights to take a weighted average of the values

You now have every piece of that formula.
